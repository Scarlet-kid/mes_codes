MODULE 01 · 5 MIN

Faire connaissance avec PHP

PHP est un langage exécuté côté serveur. Il génère du HTML que ton navigateur peut afficher. Pour commencer, écris ton code entre les balises PHP.

bonjour.php
<?php
declare(strict_types=1);

$prenom = "Sam";
echo "Bonjour, " . $prenom . " !";
À retenir

Une instruction se termine généralement par ;. Pour voir le résultat PHP, utilise un serveur local comme PHP intégré ou un environnement de développement adapté.

MODULE 02 · 7 MIN

Variables & types

Les variables commencent par $. En PHP moderne, des types explicites rendent ton code plus facile à comprendre et à maintenir.

profil.php
<?php
declare(strict_types=1);

$pseudo = "Mina";       // string
$points = 120;          // int
$estConnecte = true;    // bool
$score = 18.5;          // float

echo "{$pseudo} a {$points} points.";
À retenir

Choisis des noms explicites. Une chaîne s’écrit entre guillemets ; l’interpolation {$variable} fonctionne dans les chaînes entre guillemets doubles.

MODULE 03 · 8 MIN

Décider et répéter

Les conditions if et les boucles contrôlent le déroulement du programme. Compare les valeurs avec === pour éviter les conversions implicites inattendues.

scores.php
<?php
$scores = [12, 17, 9];

foreach ($scores as $score) {
    if ($score >= 10) {
        echo "{$score} : validé\n";
    } else {
        echo "{$score} : à retravailler\n";
    }
}
À retenir

foreach parcourt chaque élément d’un tableau. Les accolades délimitent le bloc exécuté par la condition.

MODULE 04 · 8 MIN

Organiser avec fonctions & tableaux

Une fonction nommée réutilise une logique. Les tableaux associatifs sont pratiques pour regrouper des données qui vont ensemble.

utilisateur.php
<?php
function etiquette(array $utilisateur): string
{
    return $utilisateur['prenom'] . ' — ' . $utilisateur['role'];
}

$profil = ['prenom' => 'Noa', 'role' => 'apprenti'];
echo etiquette($profil);
À retenir

Les types en entrée et en sortie documentent ce qu’une fonction attend et renvoie. Une fonction devrait faire une chose clairement.

MODULE 05 · 9 MIN

Recevoir un formulaire sans risque

Les données du navigateur ne sont jamais fiables. Vérifie le type reçu, valide ce dont tu as besoin, et échappe toute valeur avant de l’afficher dans du HTML.

accueil.php
<?php
$nom = $_POST['nom'] ?? '';
$nom = is_string($nom) ? trim($nom) : '';
?>

<form method="post">
    <label for="nom">Ton prénom</label>
    <input id="nom" name="nom" required>
    <button type="submit">Envoyer</button>
</form>

<p>Bonjour, <?= htmlspecialchars($nom, ENT_QUOTES, 'UTF-8') ?> !</p>
À retenir

htmlspecialchars aide à prévenir l’injection de HTML lors de l’affichage. En production, ajoute aussi une protection CSRF aux formulaires qui modifient des données.

MODULE 06 · 8 MIN

Lire la base de données avec PDO

PDO fournit une interface cohérente pour interroger une base de données. Les requêtes préparées séparent les données de la requête SQL.

utilisateurs.php
<?php
$pdo = new PDO($dsn, $user, $password, [
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
]);

$requete = $pdo->prepare(
    'SELECT nom FROM utilisateurs WHERE id = :id'
);
$requete->execute(['id' => $id]);
$nom = $requete->fetchColumn();
À retenir

Ne concatène jamais une entrée utilisateur dans du SQL. Garde les identifiants hors du dépôt de code, par exemple dans une configuration locale ignorée par Git.

TON PREMIER MINI-PROJET

Un compteur de visites.

Tu as vu les variables, les conditions et le HTML. Assemble-les pour afficher un message personnalisé, puis continue en ajoutant un formulaire.

  • ✓ Crée index.php
  • ✓ Lance le serveur PHP local
  • ✓ Ouvre la page dans ton navigateur
index.php
<?php
$visites = 1;
$message = "Bienvenue sur mon site !";
?>

<!doctype html>
<html lang="fr">
<body>
    <h1><?= htmlspecialchars($message, ENT_QUOTES, 'UTF-8') ?></h1>
    <p>Visite numéro <?= $visites ?></p>
</body>
</html>
$ php -S localhost:8000 # dans le dossier du projet
